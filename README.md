# 📈 商品价格监控工作台

一个**本地单文件**的商品价格监控工具：跟踪目标商品在主流电商平台与二手平台的价格，
提供每日价格看板、多平台价格对比、价格趋势分析和"何时买 / 在哪买 / 买全新还是二手"的决策建议，
帮助你以最低性价比入手心仪商品。

## 🚀 快速开始

1. 确保 `index.html` 与 `echarts.min.js` 在**同一目录**
2. 双击 `index.html`，用浏览器打开（推荐 Chrome / Edge）
3. 首次打开会弹出引导：选择「生成演示数据」先体验全部功能，或「从空白开始」直接添加自己的商品

> 数据保存在浏览器 localStorage 中，**不上传任何服务器**，仅本机可见。

## 📋 功能一览

| 页面 | 功能 |
|---|---|
| 📊 看板首页 | 今日录入进度、统计卡片（监控数/今日降价/达标数/过期数）、降价 TOP、价格动态时间线、全部商品 30 天行情速览 |
| 📦 商品管理 | 添加/编辑/删除商品；**粘贴链接自动识别平台**（淘宝/京东/拼多多/抖音/闲鱼/转转/爱回收/拍拍）；设置目标价与跟踪平台 |
| ✏️ 价格录入 | 每日快捷录价面板：显示上次价格参照、一键复制上次价、二手平台记录成色、促销标记；支持选日期补录 |
| 📉 趋势分析 | 各平台价格折线图（全新实线/二手虚线）、目标价与历史最低参考线、7/30/90 天/全部切换 |
| ⚖️ 平台对比 | 商品 × 平台最新价格矩阵（同类最低绿底高亮）、单商品平台价格条形图、**全新 vs 二手折扣分析** |
| 💡 购买建议 | 综合评分（价格历史百分位 + 目标价达成 + 二手折扣空间），给出「立即买入 / 可以入手 / 建议观望 / 考虑二手」结论及理由 |
| ⚙️ 数据管理 | JSON 导出/导入备份、演示数据生成/清空、云端迁移说明 |

## 📅 推荐的每日使用流程（约 1 分钟）

1. 打开工作台 → 点击右上角 **「✏️ 录今日价」**
2. 逐件商品填入今天看到的价格（可先点「⧉ 复制上次」再只改有变动的平台）
3. 点「保存」→ 回到看板即可看到最新的降价提醒、趋势与购买建议

> 💡 购物决策参考：看「购买建议」页的综合评分与结论徽章；已达目标价或处于历史低位（百分位 ≤15%）时通常是不错的出手时机；二手折扣 ≥35% 时值得对比成色后考虑二手。

## ❓ 为什么部分价格需要手动录入？

淘宝、京东、拼多多、抖音、闲鱼等平台均有严格的反爬机制（登录墙、验证码、风控），
个人程序直接爬取极易被拦截且随时可能失效，因此这些平台采用**手动快捷录入**策略——
可靠、零维护，数据 100% 掌握在自己手里。录入面板已针对"每天 1 分钟完成"做了专门优化。

## 🤖 自动化数据更新（GitHub Actions）

本项目内置了一套**云端定时抓取 → JSON 发布 → 工作台一键同步**的自动化链路：

```
GitHub Actions（每天北京时间 09:00 / 21:00）
  └─ sync/fetch_prices.py
      ├─ Apple 官网（全新价 + 官翻价）… 稳定主力源
      ├─ 京东 p.3.cn 当前价 … 非官方接口，需在 sync/skus.json 配置 jd_sku
      └─ 慢慢买历史回填 … 实验性，仅手动触发（见下文）
  └─ 累积写入 data/prices.json → 自动 commit
        ↓ raw.githubusercontent.com（拉取失败自动切 jsDelivr 镜像）
工作台「⚙️ 数据管理 → ☁️ 自动同步」：填入数据源 URL → 立即同步
  └─ 按商品名精确匹配 → 同平台同日期覆盖 → 记录带「🤖自动」标记
```

### 本地手动运行（无需 GitHub）

```bash
python sync/fetch_prices.py            # 抓取并更新 data/prices.json
python sync/fetch_prices.py --backfill # 额外尝试慢慢买历史回填（实验性）
```
纯 Python 标准库实现，零第三方依赖。

### 数据源配置（sync/skus.json）

- `jd_sku`：京东商品数字 ID（从 `item.jd.com/数字.html` URL 中获取）。**必须**与监控
  商品的尺寸/芯片/内存硬盘配置完全一致，否则会污染数据；填 `null` 跳过京东源。
- `cpu_cores`：CPU 核数校验（官翻同芯片有多档配置，如 M4 Pro 12核 vs 14核），
  防止高配价格错记到入门款 SKU。

### 慢慢买实验源（历史价格一次性回填）

慢慢买无官方 API。本脚本的 `--backfill` 采用「用户自供 token」策略：

1. 手机/浏览器登录慢慢买，用抓包工具（如 Chrome DevTools → Network）找到
   `getHistoryTrend` 请求，复制其中的 `token` 参数值
2. 将 token 存入 `sync/manmanbuy_token.txt`（一行即可）
3. 运行 `python sync/fetch_prices.py --backfill`

接口参数或签名随时可能变更导致失败，失败安全跳过、不影响主流程。参考开源项目：
[PPsteven/manmanbuy_js_crack](https://github.com/PPsteven/manmanbuy_js_crack)、
[DaizeDong/shopping-aggregator](https://github.com/DaizeDong/shopping-aggregator)。

### 数据源稳定性一览

| 渠道 | 自动化 | 说明 |
|---|---|---|
| Apple 官网（全新/官翻） | ✅ 稳定 | 服务端渲染，每日快照 |
| 京东 p.3.cn | ⚠️ 可用 | 非官方接口，随时可能失效；失败安全跳过 |
| 闲鱼（goofish.com） | ✅ 可行 | 需一次性扫码登录（见下文），JS 渲染解析，改版可能失效 |
| 慢慢买历史价 | 🧪 实验 | 需自供 token，仅手动回填 |
| 转转 | ❌ 已放弃 | Web 端搜索已下线（m 站废弃、PC 仅营销页），C 端全在 App/小程序 |
| 淘宝/拼多多/抖音 | ❌ 手动 | 反爬极强（签名+风控），个人不建议碰 |

### 闲鱼二手价自动抓取（Playwright）

闲鱼 Web 端（goofish.com）可登录后浏览搜索结果，基于 Playwright 实现低频抓取：

```bash
pip install playwright && python -m playwright install chromium   # 首次安装（约 150MB）
python sync/scrape_xianyu.py --login    # 弹出浏览器窗口，扫码登录闲鱼（登录态存本地，不入库）
python sync/scrape_xianyu.py            # 无头抓取：按 skus.json 的 xianyu_keyword 逐个搜索并写入 data/prices.json
```

- 抓取完成后打开工作台「数据管理 → ☁️ 立即同步」即可入库（或随 `data/prices.json` 一起推送到 GitHub 供其他设备同步）
- 过滤规则：`xianyu_tokens`（必须命中，如芯片型号）+ `xianyu_any_tokens`（任一命中，如 14寸/14英寸变体）+ `xianyu_price_floor`（价格下限，挡配件/坏价）
- 请保持低频：脚本内置 4~8 秒随机间隔；**请勿高频运行**，账号存在被风控限制的可能，建议使用小号
- 登录态失效时会明确提示重新 `--login`；GitHub Actions 不跑闲鱼源（无登录态）

## ☁️ 后续迁移云端（规划）

当前为本地单机版，数据层已收口在 `index.html` 内的 `Store` 模块。迁移到腾讯云 CloudBase 的路径：

1. 在「数据管理」页点击 **⬇️ 导出 JSON 备份**，拿到全量数据
2. 在 CloudBase 环境中将 `Store` 的读写替换为云数据库 API；可用**定时云函数**实现每天自动价格快照
3. 导入历史 JSON 即可无缝衔接，看板逻辑无需改动

## 🛠 常见问题

- **图表空白？** 确认 `echarts.min.js` 与 `index.html` 同目录
- **数据不见了？** 数据按浏览器+本地文件路径存储，换浏览器或换了文件路径属于正常隔离；用「导入 JSON」恢复备份
- **改坏了想重来？** 「数据管理」→「清空全部数据」，或重新生成演示数据
